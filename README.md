# Homebrew tap for Kubiverse

[Kubiverse](https://github.com/jairoFernandez/kubiverse): your Kubernetes cluster as a voxel world.

```bash
brew install jairofernandez/kubiverse/k8s-bridge          # the bridge (macOS, Linux); then open http://127.0.0.1:8088
brew install --cask jairofernandez/kubiverse/kubiverse    # the native macOS game
```

Updated automatically by each Kubiverse release.
